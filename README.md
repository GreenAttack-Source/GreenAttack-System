# GreenAttack-System 3.3

Paper plugin source code for the GreenAttack Minecraft server.

## Download

The installable JAR is published in [GitHub Releases](https://github.com/GreenAttack-Source/GreenAttack-System/releases).

## Build from source

Requires Java 25. On Windows, run this from the repository folder:

```powershell
.\gradlew.bat build
```

The generated JAR is written to `lib/GreenAttack-System-3.3.jar`.
